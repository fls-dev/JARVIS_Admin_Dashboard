# JARVIS Aurora — AI Agent Admin Dashboard

A dark, glassy admin template for AI agents. A glass sphere orchestrates a living canvas of task nodes with flowing edges, all set on a soft aurora glow.

## Features

- 8 app screens: Overview, Tasks, Integrations, Fine-tuning (empty state and live run), Local chat, Memory, Scheduled work, Audit trail. Plus a UI kit and a hub page.
- Orbit-wheel menu on desktop (scroll or keys 1–9), a bottom dock with a radial menu on tablet and phone, and a ⌘K command palette.
- Slide-out inspector on desktop that becomes a bottom sheet on mobile.
- Fully responsive from 1920 down to 390 px. Canvases turn into vertical flows on phones.
- Two themes (aurora and midnight) and `prefers-reduced-motion` support, with a manual override in ⌘K.
- Plain HTML, CSS and JS with no build step and no dependencies. Works from `file://`. All demo content lives in one `data.js`.

**Stack:** HTML5 · CSS (custom properties) · Vanilla JS · Canvas 2D · Inter Tight, Instrument Serif, Geist Mono (Google Fonts)
