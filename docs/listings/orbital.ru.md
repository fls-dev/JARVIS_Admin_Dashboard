# JARVIS Orbital — Spatial AI Admin Dashboard

Пространственный шаблон админки для ИИ-агента, который управляет инфраструктурой. Девять комнат вращаются вокруг одной живой 3D-планеты, каждая страница — набор стеклянных окон в сумеречном небе, а каждый переход между комнатами — полёт камеры.

## Возможности

- 11 страниц: Overview, Tasks, Operations, Local chat, Fine-tuning, Scheduled work, Memory, Integrations, Audit trail, плюс UI kit и страница-хаб.
- Орбитальная навигация: пилюля внизу раскрывается в дугу из девяти порталов (клавиша `G`). Наведение на портал поворачивает планету к комнате, клик отправляет камеру в полёт. Работают также клавиши `1–9`, `[` `]` и ⌘K.
- Планета на three.js в реальном времени: дуги трафика, орбитальные кольца и спутники-интеграции. В каждой комнате у неё своя поза.
- Адаптивность от 1920 до 390 px. На телефоне дуга превращается в нижнюю шторку 3 × 3, а зоны касания меньше 1024 px не меньше 44 px.
- Поддержка `prefers-reduced-motion` (статичный кадр, без полётов и параллакса) и статичная CSS-планета, если WebGL недоступен.
- Чистые HTML, CSS и JS без сборки. three.js и шрифты лежат внутри, работает офлайн с `file://`. Все демо-данные лежат в одном `data.js`.

**Стек:** HTML5 · CSS · Vanilla JS · three.js (WebGL) · Sora, IBM Plex Mono
