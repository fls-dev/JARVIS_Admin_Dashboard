# JARVIS Aurora — AI Agent Admin Dashboard

Тёмный стеклянный шаблон админки для ИИ-агентов. Стеклянная сфера управляет живым холстом из узлов задач с бегущими связями, а вокруг мягкое сияние авроры.

## Возможности

- 9 экранов приложения: Overview, Tasks, Operations, Integrations, Fine-tuning (пустое состояние и живой запуск), Local chat, Memory, Scheduled work, Audit trail. Плюс UI kit и страница-хаб.
- Меню-колесо на десктопе (прокрутка или клавиши 1–9), нижний док с радиальным меню на планшете и телефоне, палитра команд ⌘K.
- Выезжающий инспектор на десктопе, на мобильном превращается в нижнюю шторку.
- Полная адаптивность от 1920 до 390 px. На телефоне холсты превращаются в вертикальные потоки.
- Две темы (aurora и midnight) и поддержка `prefers-reduced-motion` с ручным переключателем в ⌘K.
- Чистые HTML, CSS и JS: без сборки и зависимостей, открывается с `file://`. Все демо-данные лежат в одном `data.js`.

**Стек:** HTML5 · CSS (custom properties) · Vanilla JS · Canvas 2D · Inter Tight, Instrument Serif, Geist Mono (Google Fonts)

**Теги:** admin dashboard, AI agent, glassmorphism, dark UI, HTML/CSS/JS
